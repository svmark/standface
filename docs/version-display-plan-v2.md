## 2. 잠자는 시간 끄기(B6)
### 무엇
정한 시간대(기본 0:00~6:00)에는 화면을 완전히 끈다. 기본은 **꺼 둠**. 알람 전 은은한 빛은 예외로 켠다.

### 지금 코드와의 관계 (StandbyScreen.kt)
- 지금 밤: `night`(어두운 방 또는 야간 모드 강제) → 밝기 0.01, 1분 무입력이면 `asleep`. 움직이거나 만지면 깨어남.
- 알람 빛(`glow`)이 켜지면 `night`가 꺼지고 호박색 빛이 나옴.
- 새 상태 `quiet`(잠자는 시간)를 `glow`보다 아래, `night`/`asleep`보다 위에 둔다. 우선순위: 알람 빛 > 잠자는 시간 > 밤 > 낮 쉬기 > 낮.

### 동작 규칙
| 상황 | 동작 |
|---|---|
| 잠자는 시간 + 알람 빛 아님 | 순검정(OLED 픽셀 꺼짐) + 밝기 최저. 시계·배터리·알림 배너 모두 안 그림 |
| 알람 15분 전~울림 | 지금처럼 알람 빛이 나옴(잠자는 시간이어도). 알람을 끄면 다시 검정 |
| 움직임 | **깨우지 않음**(침대 흔들림에 켜지는 것 방지). 그래서 이 시간에는 가속도 센서도 끔 → 배터리 절약 |
| 화면 터치 | 시각을 10초만 보여주고(지금 밤 화면과 같은 어두운 모습) 다시 검정 |
| 새 알림·음악 | 깨우지 않음 |
| 충전기에서 뗌 | 지금처럼 닫힘 |
| 시간대가 자정을 넘김(22:00~06:00) | 지원 |
| 설정 안 한 사람 | 아무 변화 없음(기본 꺼짐) |

"완전히 끈다"의 뜻: 앱은 시스템 화면을 직접 끌 수 없다(기기 관리자 권한 필요). 대신 검정 화면 + 최저 밝기로 OLED를 꺼진 것과 같게 한다. 화면 끄기 시간(폰 설정)과 AOD는 건드리지 않는다. 삼성 AOD가 먼저 뜨는 문제는 기존 루틴 방식 그대로.

### 설정 화면 ("침대 옆 시계" 절)
- `잠자는 시간 끄기` 켜기/끄기 (기본 끄기)
- 켜면 `시작 00:00` · `끝 06:00` 두 시각 선택(TimePicker 대화상자, 30분 단위가 아니라 분 단위)
- 설명 문구: "정한 시간에는 화면을 검게 해요. 알람 전 은은한 빛은 켜져요. 화면을 만지면 10초 동안 시각이 보여요."

### 구현 순서
1. `Settings.kt`: `quietEnabled`, `quietStartMin`, `quietEndMin`(0~1439) 추가, 읽기·키.
2. `data/QuietHours.kt`(새 파일): `isQuiet(nowMinutes, start, end)` 순수 함수. 자정 넘김, 시작=끝(=항상 꺼짐 방지: 끈 것으로 처리) 처리.
3. `StandbyScreen.kt`: `quiet` 계산(분 단위로 `tick`에서), 밝기·팔레트·가속도 센서 사용 여부·터치 깨우기 10초 반영. `onRest` 호출은 `asleep || rested || quiet`(3버튼 막대 숨김 유지).
4. `MainActivity.kt`: 설정 UI.
5. 테스트: `QuietHours` 단위 테스트(일반, 자정 넘김, 경계 시각, 시작=끝), 화면 스냅숏 2장(잠자는 시간 검정, 터치 10초 시각), 번인 측정 테스트에 잠자는 시간 화면 0.0% 추가.
6. 에뮬레이터 확인: 시간대를 현재 시각 포함으로 설정 → 검정, 알람 시각을 가까이 잡아 빛이 나오는지, 터치 10초. 폴드8 실기기 하룻밤 확인.

### 위험·주의
- 시스템 시계를 바꾸거나 시간대를 옮기면 경계가 어긋날 수 있음 → 시각은 매번 `now`에서 계산하고 저장하지 않음.
- 잠자는 시간에 알람이 없으면 아침에 시각을 못 볼 수 있음(터치하면 10초 보임). 설명에 적음.
- 잠자는 시간 중 폰을 뗐다 올리면(루틴 재실행) 같은 검정 상태로 열림.
- 새 문구 몇 개가 영어 선택 화면에도 필요함(`LocalKorean` 패턴).
