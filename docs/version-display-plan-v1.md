# 앱에 버전명 넣기 · 추가 기능 계획 v1 (2026-11-02)

기획 단계예요. 코드는 아직 고치지 않았어요.

## 1. 왜 필요한가
- 테스터가 "어느 버전이에요?"라는 질문에 답하기 어려워요. 앱 정보(설정 › 앱)까지 들어가야 보여요.
- beta가 매주 나오고(beta.1~5, 열흘) 제보가 Threads·GitHub로 와서, 제보에 버전이 있어야 고쳐졌는지 따질 수 있어요.
- 스크린샷만 받아도 버전을 알 수 있게 하고 싶어요.

## 2. 어디에 보여줄까
| 위치 | 내용 | 비고 |
|---|---|---|
| **설정 화면 맨 아래 (필수)** | `Standface 1.1.0-beta.5 (7)` 작은 회색 글씨 | Spacer(24dp) 자리 바로 위. 길게 누르면 클립보드 복사 + "복사했어요" 토스트 |
| 설정 화면 맨 위 제목 옆 (선택) | 베타일 때만 `테스트판` 작은 칩 | 정식(-beta 없음)이면 안 보임. 정식과 테스트판 구분용 |
| 스탠바이 화면 | **넣지 않음** | 하루 종일 켜져 있어 번인 위험. 번인 대책 기조에 어긋남 |
| 처음 설정 화면 | 설정 화면과 같은 화면이라 따로 안 함 | |

## 3. 구현 방법
1. `app/build.gradle.kts`의 `buildFeatures`에 `buildConfig = true` 추가. (지금 꺼져 있음. APK 크기 영향 거의 없음)
2. 설정 화면에서 `BuildConfig.VERSION_NAME`, `BuildConfig.VERSION_CODE` 사용. 버전을 두 군데 적지 않아 RELEASING.md 순서(build.gradle.kts만 고침)가 그대로예요.
3. 문자열은 MainActivity의 다른 글처럼 한국어 하드코딩(영어 선택 시 번역 대상인지 strings.xml 패턴 확인 후 맞춤).
4. 복사 문구: `Standface 1.1.0-beta.5 (7) · Android 16 · SM-F971N` — 제보에 그대로 붙여 넣을 수 있게 기기와 안드로이드 버전을 포함. 개인정보 없음.
5. 테스트: 화면 스냅숏 중 설정 화면 기준 그림이 있으면 다시 찍음(`recordRoborazziDebug`). 예시 데이터는 FixedSources처럼 고정 문자열을 넣어 버전이 올라도 그림이 안 바뀌게.
6. 작업량: 약 0.5일(코드 1시간 + 기준 그림·CHANGELOG·확인).

## 4. 결정이 필요한 것
